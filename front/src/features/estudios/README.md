# Estudios

Feature para las páginas y los flujos completos relacionados con estudios de
exoma: seguimiento, estados, consulta y resultados según los permisos del
perfil. Agregar aquí las vistas, componentes exclusivos, hooks, estilos y
pruebas de esos flujos. Compartir fuera de esta carpeta solo las piezas que
tengan reutilización real.
