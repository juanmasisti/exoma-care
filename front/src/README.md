# Código fuente

Código de la aplicación React. Aquí se esperan el punto de entrada, la
composición de la aplicación, estilos y carpetas que agrupan funcionalidades,
componentes y servicios.

- `main.jsx` inicializa React, estilos globales y proveedores de aplicación.
- `App.jsx` configura la composición principal y las rutas de páginas.
- Los estilos globales van en hojas claramente compartidas; los estilos
  específicos de una vista o componente deben permanecer junto a esa pieza.
- [`assets/`](./assets/README.md), [`components/`](./components/README.md),
  [`features/`](./features/README.md), [`services/`](./services/README.md) y
  [`store/`](./store/README.md) tienen responsabilidades separadas.
