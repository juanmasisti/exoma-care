# Persistencia y base de datos

Configuración de SQLAlchemy y elementos que describen o inicializan la base de
datos. Se esperan sesiones/conexiones, modelos ORM y utilidades controladas de
inicialización o carga de datos de desarrollo. No guardar aquí archivos de base
de datos con datos sensibles ni credenciales.

`models.py` define los modelos actuales; `session.py`, la configuración de
sesión; `security.py`, el hash/verificación de contraseñas; y `seeder.py`, los
datos iniciales de desarrollo.
